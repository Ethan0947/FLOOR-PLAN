## 🤔 為什麼做這個？

帶看房屋時，客戶常常難以理解格局。這個工具可以**當場繪製格局圖**，讓客戶一目了然，比手繪或口頭說明更有說服力。

## ✨ 功能列表

| 功能 | 說明 |
|------|------|
| ↩️ **Ctrl+Z 復原** | 支援多步驟撤銷/重做 |
| ➖ **點對點畫牆** | 點第一點設起點，點第二點完成，直觀不歪 |
| 〜 **三點弧線** | 三點定弧：起點 → 終點 → 控制弧度，可畫任意弧形牆 |
| ┄ **虛線功能** | 標示陽台外推、平台外移等示意 |
| 🪣 **框填色** | 點擊畫出任意多邊形範圍，自動填入選定顏色 |
| 🌗 **半圓形陽台** | 放射狀玻璃帷幕效果 |
| 📏 **尺寸標註** | 可自訂長度標示 |
| 🔲 **格線吸附** | 自動對齊格線，繪圖更整齊 |
| 🎨 **填色** | 10 種常用顏色快速填色 |
| ❓ **使用說明** | 右上角 ？按鈕彈出完整說明視窗 |
| 💾 **存圖** | 匯出高解析度 PNG |

## 🪣 框填色使用方式

1. 點選左側 **🪣 框填色** 模式
2. 先在色板選好要填的顏色
3. 依序點擊畫出範圍（至少 3 個點）
4. 完成方式任選一種：
   - **雙擊** 結束
   - **點擊起點**（綠色圓圈）閉合
   - 按 **Enter** 確認
5. 按 **Esc** 取消
