## 🤔 為什麼做這個？

帶看房屋時，客戶常常難以理解格局。這個工具可以**當場繪製格局圖**，讓客戶一目了然，比手繪或口頭說明更有說服力。

---

## 📋 完整物件庫

| 類別 | 物件 |
|------|------|
| 🚪 門窗陽台 | 推門、拉門（平移門）、窗、玻璃帷幕陽台、**半圓形陽台**、**弧形陽台（四分之一圓）**、柱子、指北針 |
| 🪜 樓梯 | 直梯、旋轉梯、L型梯 |
| 🚿 衛浴 | 馬桶、浴缸、洗手台、淋浴 |
| 🍳 廚房 | 瓦斯爐、流理台、冰箱 |
| 🛋️ 家具 | 單/雙人床、沙發、餐桌（含椅子）、書桌、衣櫃 |

---

## ✨ 功能列表

| 功能 | 說明 |
|------|------|
| ↩️ **Ctrl+Z 復原** | 支援多步驟撤銷/重做 |
| ➖ **點對點畫牆** | 點第一點設起點，點第二點完成，直觀不歪 |
| 〜 **三點弧線** | 三點定弧：起點→終點→控制弧度，可畫任意弧形牆 |
| ┄ **虛線功能** | 可用於標示陽台外推、平台外移等示意 |
| 🌗 **半圓形陽台** | 放射狀玻璃帷幕效果 |
| ◔ **弧形陽台** | 四分之一圓轉角型陽台 |
| 📏 **尺寸標註** | 可自訂長度標示 |
| 🔲 **格線吸附** | 自動對齊格線，繪圖更整齊 |
| 🎨 **填色** | 8 種常用顏色快速填色 |
| 💾 **存圖** | 匯出高解析度 PNG |

---

## ⌨️ 快捷鍵

| 按鍵 | 功能 |
|------|------|
| `Ctrl+Z` | 復原 |
| `Ctrl+Y` | 重做 |
| `Delete` / `Backspace` | 刪除選取物件 |
| `Esc` | 取消繪製 |
