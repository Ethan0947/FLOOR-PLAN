## 🤔 為什麼做這個？

帶看房屋時，客戶常常難以理解格局。這個工具可以**當場繪製格局圖**，讓客戶一目了然，比手繪或口頭說明更有說服力。

靈感來自小時候玩的**百變恰吉**遊戲——那種斜角俯視的空間感，正是讓人直覺理解格局的方式。

## 🖼️ 底圖描邊使用方式（V3.4 新增）

1. 點選側欄 **📎 上傳底圖**，選擇格局圖照片
2. 調整**透明度滑桿**（建議 30-50%）
3. 切換**實線牆**或其他繪圖模式，沿著底圖邊緣描繪
4. 加上**標尺**和**文字標籤**
5. 按**💾 存圖**——底圖會自動隱藏，只匯出你描的線

---

## 🪣 框填色使用方式

1. 點選左側 **🪣 框填色** 模式
2. 先在色板選好要填的顏色
3. 依序點擊畫出範圍（至少 3 個點）
4. 完成方式任選一種：
   - **雙擊** 結束
   - **點擊起點**（綠色圓圈）閉合
   - 按 **Enter** 確認
5. 按 **Esc** 取消

## ⌨️ 快捷鍵

| 按鍵 | 功能 |
|------|------|
| `Ctrl+Z` | 復原 |
| `Ctrl+Y` | 重做 |
| `Ctrl+C` | 複製選取物件 |
| `Ctrl+V` | 貼上（每次偏移 20px，可連貼） |
| `Ctrl+D` | 快速複製並偏移（不需先按 C） |
| `Delete` / `Backspace` | 刪除選取物件 |
| `Enter` | 完成框填色 |
| `Esc` | 取消繪製 |

> 快捷鍵修正說明：V3.4 改用 `window.addEventListener + capture phase` 搭配 `document.activeElement` 判斷，解決 Fabric.js 隱藏 textarea 搶走 focus 導致快捷鍵全部失效的問題。
