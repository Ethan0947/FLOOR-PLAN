# Ethan 格局神器 V4.0

> 專為房仲設計的格局平面圖繪製工具

## 簡介

格局神器是一款輕量、免安裝的瀏覽器格局平面圖繪製工具，專為台灣房屋仲介人員設計。無需後端、無需登入，開啟即用，支援底圖描邊、物件拖放、圖層管理、一鍵匯出等功能，讓格局圖製作變得快速直覺。

## 使用方式

直接用瀏覽器開啟 `floor_plan_index.html`，無需安裝任何套件或伺服器。

```
雙擊 floor_plan_index.html → 瀏覽器開啟 → 開始繪圖
```

建議使用 Chrome 或 Edge 最新版本以獲得最佳體驗。

## 功能特色

- 實線牆、虛線、弧線、框填色、點擊填色等多種繪圖模式
- 完整物件庫：門窗陽台、樓梯、衛浴、廚房、家具、幾何空間
- 底圖描邊：上傳照片置底，調整透明度後描繪
- 圖層管理：拖移排序、顯示/隱藏、鎖定物件
- 智慧存圖：依物件 Bounding Box 自動裁切，2× 解析度輸出
- 顏色選擇器：Hex 色碼輸入 + 最近使用顏色記錄
- 畫布平移：Space + 拖曳 或 中鍵拖曳
- 對齊輔助線：拖移時自動顯示橘色對齊線
- 50 步 Undo / Redo，記憶體保護機制
