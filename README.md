# Ethan 格局神器 V10

> 專為台灣房仲設計的格局平面圖工具：拿到一張別人的格局圖，描完就有坪數，修成照比例，交給客戶。

## 簡介

格局神器是一個**單一 HTML 檔**的瀏覽器工具，免安裝、免登入、沒有後端。所有資料都存在你自己的瀏覽器裡，不會上傳到任何伺服器。

V10 的重點是讓格局圖**「可以算、可以信」**：
- 描出牆，就能量出每一間的坪數。
- 用成果圖或實際丈量的尺寸，把沒照比例的格局圖修正回來，而且不破壞格局。
- 用不同顏色區分空間、加上圖例，一鍵做出 2.5D 裝修示意，並輸出成 A4、帶比例 PDF、Excel、簡報。

## 使用方式

```
雙擊 index.html → 瀏覽器開啟 → 照「新手教學」走一遍
```

- 建議使用 Chrome 或 Edge 最新版。
- 繪圖核心 Fabric.js 從 unpkg CDN 載入，**第一次開啟需要網路**。
- 第一次開啟會自動播放新手教學。完整說明在右上角「說明」，照工作順序寫，可以搜尋。

## 一張圖的工作流程

| 順序 | 做什麼 | 在哪裡 |
|---|---|---|
| 1 | 上傳底圖；手機拍歪的先「照片拉正」 | 右側「底圖描邊」 |
| 2 | 校正比例：用最長、最可靠的一段 | 工具列「比例」或按 `C` |
| 3 | 描牆：自動描牆，或手畫 | 「自動描牆」、「實線牆」或按 `W` |
| 4 | 整理牆線 | 「整理」或按 `T` |
| 5 | 量房間、選用途和類別 | 「房間」或按 `R`、「面積表」 |
| 6 | 用已知尺寸修正：成果圖、實量 | 牆的「已知長度」→ 面積表「軸線法」 |
| 7 | 放門窗、家具、尺寸線、圖例 | 素材庫、「尺寸線」或按 `M` |
| 8 | 輸出 | 標頭「輸出」 |

## 功能特色

**算坪數**
- 比例校正有三種方式：點兩點、尺寸線、已知坪數反推。
- 點進封閉區域就自動量出房間的㎡和坪。牆有小缺口、門洞，會自動補上邊界。
- 面積表可分類「室內／陽台露台／增建／庭院」，增建和庭院不計入室內合計。也可以選擇扣除牆厚算淨面積。
- 長方形房間可以直接改「寬×深」，牆會跟著移動。

**修正沒照比例的圖**
- 已知長度要標明來源：**成果圖**（量到外牆外緣）或**實量**（測距儀量的牆面到牆面）。程式會依牆厚自動換算，牆厚不用量。
- **軸線法**：只調整牆與牆之間的距離，不破壞格局。相連的牆仍然相連、橫直不變、房間順序不變，底圖也一起變形對齊。
- **橫直分開估算**：整張圖在一個方向被壓扁或拉長時使用。
- 每個已知長度都列出誤差，特別不合理的數字會標 ⚠ 並說明原因。

**描圖更順**
- 自動描牆：橫、直、斜的牆都抓得到，文字筆畫不會被當成牆；可以框選其中一層描牆，拆成新樓層。
- 吸附：端點、中點、交點、垂直、牆上任一點、對齊追蹤線、磁吸到底圖牆線的正中央。
- 整理牆線（`T`）：差一點沒接上的延伸接上、多出一截的剪掉、斷成幾截的接起來。兩道牆接直角（`J`）。
- 照片拉正（四點透視校正）、底圖白底透明、亮度與對比調整。

**素材與標註**
- 門窗放到牆邊自動吸上去，門會自動挖出門洞。家具自動靠牆貼齊，拖曳時有對齊參考線。
- 素材依比例自動換成真實尺寸。
- 智慧尺寸線：牆移動時跟著更新，也可以一鍵標出每間房的寬和深。
- 空間用途配色（7 類）、圖例自動更新、地板材質、線型。

**輸出與展示**
- PNG（彩色、灰階、黑白影印）、SVG、DXF 匯入匯出、A4 一頁版（可存 PDF）。
- 帶比例 PDF：在 Acrobat 用量測工具就能直接量出公尺。
- 面積表 Excel（合計是公式）、各樓層簡報（PPTX）。
- 一鍵 2.5D 裝修示意：5 種風格，空房間依用途自動擺示意家具。
- 帶看展示模式、坪數圓餅或橫條圖、價格試算、浮水印。

**不怕做白工**
- 多樓層、專案檔（`.geju.json`）、自動保留最近 5 個復原點、步驟列表。
- 「🧪 自我檢查」：64 項自動測試（內建情境，不代表所有情況都正常；重要的圖請先另存專案），會借用畫布跑完再自動還原。

## 重要提醒

- **面積一律是估算值**，由圖上描繪加比例換算而來，**不是實測，也不是權狀登記面積**。對外請寫「約 X 坪（依圖估算）」。
- 2.5D 是示意圖：家具是方塊組成的量體，自動擺放也不會考慮動線。
- 底圖若來自他人（其他仲介的格局圖、成果圖），請自行留意著作權與使用範圍。本工具不提供去除浮水印的功能。

## 技術說明

- 單一 HTML 檔：V9.2 原始程式，再依序加上 V10 的 17 個增補模組。

- 沒有後端，資料存在瀏覽器 localStorage。Excel、PPTX、PDF 都是由瀏覽器本機產生。
